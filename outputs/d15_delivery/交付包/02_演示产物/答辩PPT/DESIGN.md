# DESIGN.md —— 双人对话播客自动生成系统 · 答辩 PPT

> 本文件是 17 页的**设计宪法**。所有 `slides/*.slide` 的样式只允许来自本文件。

## 〇、零、本项目的两条设计主张（先说结论）

**主张一：白纸黑字，不要「科技感」。**
用户明确要求主色调为白色、语言口语化、去 AI 味。落实到设计上就是：**白底、墨黑字、一条细线、一点朱橙**。没有深色底图、没有渐变、没有发光、没有玻璃拟态、没有圆角阴影卡片墙——那些是「PPT 模板」的信号，不是「做过一个系统」的信号。

**主张二：全篇不使用 ImageGen 生成图。**
理由四条，逐条可查：
1. 这是**答辩**材料。评委见过太多 AI 生成图，「看着像 AI 做的」是负分项；真机截图才是加分项。
2. 全篇主视觉都能由**真实产物**承担：真机界面截图、真机数值、真实结构图。
3. `design-principle` §5「允许 SVG」明确覆盖：流程图、时间轴、架构图、巨型数字、进度环、背景网格——本项目需要的图全在这一类。
4. 具象场景图（人、城市、会议室、机房）本主题一个都不需要。
→ 全篇图片 = **6 张真机截图（材料图 P0）+ SVG / 结构排版图**。风格天然统一（同一套 UI 皮肤 + 同一套线稿），不存在「摄影/插画/3D 混用」问题。

## 一、画布与母版（A/B/C 三区）

**画布**：1280 × 720 px（16:9）。

**页面 padding**：上 20 / 下 20 / 左 72 / 右 72 → 内容可用宽度 **1136 px**，可用高度 **680 px**。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 20–120 px | 100 px | 主标题 34px bold `#15171B`；标题右下方 1 行 `14px` 灰色限定语（口径/单位/适用范围）；**右侧固定放章节标签（`01 做出来的是什么` 这类 13px mono 灰字），全篇 x 坐标一致** |
| **B · 内容区** | 120–660 px | **540 px** | 一切正文、结构图、截图、台账表。禁止挤占 A / C 区 |
| **C · 页脚条** | 660–700 px | 40 px | 左侧 `13px` 灰字项目名「双人对话播客自动生成系统 · 答辩」；右侧 `13px` mono 页码 `NN / 17`。**左侧另放 1 根 2px 朱橙短横线（宽 18px）作全篇统一的 L3 角标**，位置全篇一致 |
| 底部留白 | 700–720 px | 20 px | 空白 |

**A 区硬约束**：标题块**右侧只放章节标签文字，不放任何装饰小图**（禁止 200×70 贴片）。全篇 A 区结构与位置**逐页一致**。

**C 区硬约束**：**内容页（P2~P16）必须有完整 A/B/C**。封面（P1）与结束页（P17）允许省略 C 区、采用自定义版式。

**高度预算模板（每页复用）**：
```
上 padding 20
+ A 标题块 100
+ B 内容区 540      ← 内部再分配，总和必须 = 540
+ C 页脚条 40
+ 下 padding 20
= 720              ← 恰好用满，不允许溢出
```
B 区的 540px 在每页内部按下方「页面映射表」的 `B 区高度分配` 列切分；**该列各行之和必须等于 540**（含 gap）。

**页脚页码的唯一权威是文件名**：`09.slide` 必须写 `09 / 17`。增删页面后一律用
`python scripts/renumber_slides.py <slides_dir> --renumber --total 17` 重排，**不要手改**——
页脚不是内容，lint 查不出来，错了不会有任何测试变红。（该脚本以 `{/* C · 页脚条 */}` 为锚点，
只在锚点之后改写，避免把正文里的 `12 / 12` 这类真实数据当成页码。）

## 二、颜色系统（共 4 个 hex，不允许出现第 5 个）

| 角色 | HEX | 用途 |
| :--- | :--- | :--- |
| **纸白**（背景 / 主色） | `#FFFFFF` | 页面背景、卡片底、大面积留白 |
| **墨黑**（文字 / 深色块） | `#15171B` | 标题、正文、深色标签块、截图细边框、分割线 |
| **朱橙**（**唯一强调色**） | `#D9480F` | 焦点数字、当前节点、关键标记、L3 短横线 |
| **石墨灰**（中性 / 次级） | `#6E7480` | 次级说明、页脚、单位、限定语 |

**第 5 个颜色怎么办**：不允许新 hex。需要更浅的底/更淡的线时，**用同一个颜色 + `opacity`**：
- 细分割线：`<Box style={{ background: '#15171B', opacity: 0.12, height: 1 }} />`
- 更淡的强调底：`<Box style={{ background: '#D9480F', opacity: 0.08 }} />`
- 截图降噪（未聚焦的次要截图）：`<Image style={{ opacity: 0.94 }} />`

> ⚠️ **`opacity` 是「组不透明度」，会乘到整棵子树上。**
> `<Box style={{ background:'#15171B', opacity:0.06 }}><Text style={{color:'#15171B'}}>…</Text></Box>`
> 这种「靠容器 opacity 做淡底」的写法，会把里面的文字一起压到 6% 不透明度 —— 结果是**白底白字**，
> 而 `slidep lint` 全过（它只查语法与溢出，判不了「看不看得清」）。
> **要淡底就用实色**（如 `#EEF0F3`），文字另给足对比度。判据见 `scripts/check_slide_contrast.py`（WCAG 2.1）。

**禁止**：渐变、boxShadow、彩色描边、深色整屏背景、第二套强调色。

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 纸白 `#FFFFFF` | **70 ~ 82%** | 白底是「无色」的底纸，不参与主/辅/强调的面积博弈；本项目把它固定在绝对主导地位，这就是「白色主色调」的落实方式 |
| 墨黑 `#15171B` | **≤ 20%** | 文字与深色标签块 |
| 石墨灰 `#6E7480` | **≤ 8%** | 次级信息 |
| 朱橙 `#D9480F` | **≤ 8%**（常规页）／**≤ 18%**（Hero 页 P1 / P14 / P17） | **只允许出现在焦点元素上**：巨型数字、当前流程节点、L3 短横线、判断句的行首标记 |

**色彩节奏**：P6（截图墙几乎全白）、P10（一条橙色刻度线把版面切开）、P14（巨型橙色数字）三页色彩比例与其余页**显著不同**，满足「至少 2 页比例不同」。

**判断句的统一视觉**：全篇 `判断句` 一律用 `朱橙 2px 左边框 + 17px 墨黑文字`，不用引号、不用卡片。

> **已知偏差（如实登记，不改）**：朱橙 `#D9480F` 在白底上的对比度是 **4.30:1**，比 WCAG AA 的 4.5 差一点点。
> 涉及页码、K1~K6 编号、时间轴标签等 20 处，全为**加粗或 ≥ 13px** 的短标识。压深到 `#C2410C` 可达 5.2:1，
> 但会改变全篇视觉调性，故保留现状并由 `check_slide_contrast.py` 记为 WARN 而非 FAIL。

## 四、信息密度门禁（本项目取值）

| 页面类型 | 正文字数下限 | 图片/图表下限 | 主视觉占 B 区面积 |
| :--- | :--- | :--- | :--- |
| 封面 | 40 | ≥ 1（三张截图） | ≥ 35% |
| 目录 | 120（合计） | 0–1 | — |
| 内容页 · 单主题 | **180** | 1 | **≥ 30%** |
| 章节过渡 | 70 | 1（大数字） | ≥ 40% |
| 结束页 | 40 | 1（数字带） | — |

**留白上限**：常规内容页 **≤ 35%**。封面 / 章节过渡 / 结束页不受此限（P17 留白约 40%，围绕中央大数字，属「焦点留白」）。

**容器填充率**：本项目**不使用增高卡片**，所有分栏都是「顶对齐的文字块 + 一条细分割线」，因此不触发 §4.1 的卡片填充率门禁；但仍遵守**横向兄弟块 y 轴对齐**：同一行两个栏位的小标题 y 坐标必须一致。

**每页必须有 ≥1 个视觉锚点**，满足下列任一即可：≥ 44px 的元素；**覆盖 B 区 ≥ 40% 宽度的结构轴**（如 P9 流程链、P11 四段阶段轴）；或占 B 区 ≥ 40% 的图。逐页锚点见映射表 `锚点` 列。
